# AWS-EKS-Kubernetes
**AWS EKS Advance demo manifests** Note EKS cluster deployed on AWS.

This is basically used for AWS EKS Labs (AWS EKS Cluster) - example with **AWS EFS Setup, AWS OIDC configuration , Service Account, IAM policy, Namespace**  etc..

**Tomcat app** deployment manifest with EFS mount , persistent volumes configuration.

**Fluent-Bit** Configuration manifests deployment and ServiceAccount and COnfigMaps.

**Kube-State-Metrics** manifests deployments, service , ServiceAccount and Kube-stat-Metric RBAC role

**Node-Exporter manifests** - namespace, ServiceAccount, ClusterRole, deployment, Service
