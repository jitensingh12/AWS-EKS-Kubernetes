Note: We have already started EKS cluster in AWS.

EFS-CSI-DRIVER ADDON.

curl -S https://raw.githubusercontent.com/kubernetes-sigs/aws-efs-csi-driver/master/docs/iam-policy-example.json -o efs-iam-policy.json

Create an IAM Policy 

aws iam create-policy \
  --policy-name AmazonEKS_EFS_CSI_Driver_Policy \
  --policy-document file://efs-iam-policy.json

Create the IAM Role via IRSA using

Please check OIDC attached or not -

aws eks describe-cluster \
  --name test-cluster \
  --region us-east-1 \
  --query "cluster.identity.oidc.issuer" \
  --output text

Attachment is being done by below

 eksctl utils associate-iam-oidc-provider \
  --region=us-east-1 \
  --cluster=test-cluster \
  --approve

Create Service account for for EFS CSI driver - this will create a role as well.

eksctl create iamserviceaccount \
  --cluster test-cluster \
  --region us-east-1 \
  --namespace kube-system \
  --name efs-csi-controller-sa \
  --attach-policy-arn arn:aws:iam::707318434536:policy/AmazonEKS_EFS_CSI_Driver_Policy \
  --approve

Get the role info using below command. That is being used while creating EFS Addon.

aws iam get-role \
  --role-name $(kubectl get sa efs-csi-controller-sa -n kube-system -o jsonpath="{.metadata.annotations['eks\.amazonaws\.com/role-arn']}" | awk -F'/' '{print $NF}') \
  --query "Role.Arn" \
  --output text

Once done create the Addon for EFS CSI driver

aws eks create-addon \
  --cluster-name test-cluster \
  --region us-east-1 \
  --addon-name aws-efs-csi-driver \
  --service-account-role-arn arn:aws:iam::707318434536:role/eksctl-test-cluster-addon-iamserviceaccount-k-Role1-WWfHaybCXQcK



by EKSctl

eksctl create addon \
  --cluster <YOUR_CLUSTER_NAME> \
  --region <YOUR_AWS_REGION> \
  --name aws-efs-csi-driver \
  --service-account-role-arn arn:aws:iam::<AWS_ACCOUNT_ID>:role/<ROLE_NAME_CREATED_ABOVE> \
  --force



Verify installation

kubectl get pods -n kube-system -l "app.kubernetes.io/name=aws-efs-csi-driver"



kubectl describe pod pod-name -n logging | grep -E "AWS_ROLE_ARN|AWS_WEB_IDENTITY_TOKEN_FILE"
